# Implementation decisions

The script is standalone: at runtime it reads only `dataset_1.csv` through `dataset_4.csv` in `--data`. The dictionaries were used to identify columns during implementation; they are not runtime dependencies. The synthetic data are used solely for execution and computational checks.

- `dataset` is the integer 1–4. Dataset 1 uses the original text `part_uid` as its unit identifier. Datasets 2–4 use the original one-based file row number, assigned before filtering. `samples.csv` contains each retained unit once per sample level, including units that have missing analysis variables or cannot form a valid pair. A missing dataset 1 identifier receives a distinct row-specific placeholder so unrelated missing identifiers cannot be paired.
- Dataset 1 attention filtering precedes structural pairing. Exactly two retained rows, one loyal and one control, make a person eligible for paired analyses. This eligibility also applies to paired subgroup tests. Stacked summaries, reliability estimates, mixed models, and independent subgroup tests use their own complete cases among all sample-retained rows. `N1.n` counts structurally eligible persons; each `P1.*.n` counts persons with both measurements observed for that outcome. Every retained person, including an ineligible pair, has an influence deletion row.
- Dataset 1 age uses the first row in file order for each retained person. For the differences ANOVA, wrongdoing is the person's unique nonmissing value across the two rows; disagreement makes that person's factor missing. The main condition effect is the intercept of a regression of differences on sum-coded observed wrongdoing levels, so it equally weights scenario means. The interaction is the omnibus regression F test. The mixed models contain a fixed intercept and condition coefficient; the second model has independent random intercepts for wrongdoing and for persons nested in wrongdoing, with no additional fixed wrongdoing effect. REML tries L-BFGS, BFGS, then Powell if necessary and requires convergence and finite condition uncertainty. Boundary variance fits can be valid; reported warnings are saved in `session_info.txt`.
- Stored condition codes and explicitly provided reversed items are used as supplied. The only newly reversed item is the requested `8 - inttrust_accused3` variant. Item means and sums require every item. The general missing-item rule also masks a deposited composite whenever any of its specified items is missing; otherwise its deposited value is preserved, without rescaling. Transformed dataset 4 predictors are used as deposited because their transformation formulas were not specified.
- Each mediation system uses one common complete-case sample across its predictor, outcome, and all mediators in that system. All mediator equations, the outcome equation, and the total-effect equation use that sample. Parallel and simultaneous mediation therefore share samples across mediator paths; separate single-mediator models can have different samples. This resolves the unspecified relationship between complete cases for a multi-equation quantity and its component coefficients, and makes each bootstrap a resampling of intact model observations. The total effect is the coefficient from outcome on condition alone on that same sample. Classical OLS standard errors enter the specified delta formulas, without cross-equation covariance terms. Logistic mediator outcome coefficients are on the log-odds scale.
- A parallel or simultaneous system has one bootstrap stream and one resampled row set per replicate for all its paths. Single and serial systems have distinct streams. Streams derive from the seed and a stable SHA-256 identity containing dataset, sample level, composite level, method, and model keys. They do not depend on Python's randomized hash or model traversal order. Exactly `--boot` attempts are made. Rank deficiency, nonconvergence, separation, or nonfinite fit coefficients/uncertainty count as failed fits. A failed simultaneous system replicate is discarded for every path in that system. Each path reports its count under `.boot_failed`; these counts can describe the same replicates and should not be summed across paths as independent failures.
- Bootstrap intervals use NumPy's linear-interpolation empirical quantiles. Bias correction uses the exact requested below-estimate fraction with half weight for exact ties. Fractions of zero and one give infinite bias corrections and the corresponding endpoint quantiles, without artificial clipping. At least two successful replicates are required for bootstrap standard errors and intervals. Bootstrap quantities are omitted at composite levels where the manifest prohibits bootstrapping. There is no bootstrap for dataset 1.
- Dataset 3 ANOVAs use categorical factors with sum coding for all three SS types, with relationship before history and interaction. Type III tests therefore use the requested sum-to-zero parameterization; type I follows the specified sequential order. Classical eta squared divides by the outcome's corrected total SS on the full model's complete-case sample. Pooled contrasts and their HC3 counterparts require the four-cell model to be estimable; Student and Welch contrasts and descriptive effect sizes remain available when their own cells suffice. Cell `n` is the number with observed outcome and both factors. `C3.cell.<outcome>.<cell>` preserves the manifest's literal key structure.
- Logistic models use unpenalized maximum likelihood with an intercept named `Intercept` in term keys. Null log likelihood uses an intercept-only Bernoulli model on precisely the fitted model's sample. Model SEs use the inverse observed information; HC0 uses the inverse Hessian and individual score outer products without a finite-sample multiplier. Alternatives report the predictor's quantities, as requested. Separation or nonconvergence is a failed fit, without regularization or another estimator. Pearson chi square treats the observed strong-predictor values as categories and applies no continuity correction.
- Two-sample descriptive summaries use nonmissing outcomes within each specified group. Paired summaries use complete outcome pairs. Dataset 4 signed share is the number equal to 1 divided by the number with observed `Signed`; `N4.n` counts all rows retained by its loyalty filter. Age summaries use their own available cases. Numeric nonfinite values are treated as missing, as are unparseable numeric text values; no trimming, range-based exclusions, or outlier filters are applied.
- Methods left unnamed by the manifest are labeled `descriptive` for counts, means, and SDs, `pearson` for correlations and chi square, and `cronbach_alpha` for alpha. Explicitly specified method labels are preserved. P values are computed as two-sided probabilities without rounding; robust and delta/Wald tests use normal tails, and t/F tests use their stated degrees of freedom. CSV floats use 17 significant digits to preserve double precision. Undefined quantities get `status=failed`, a blank numeric value, and a reason. Successful zero p values from numerical underflow are not replaced with thresholds.
- Influence analyses delete each sample-retained unit before recomputing the specified analysis, including units not used by that particular model because of missing data. A deletion that leaves the fitted sample unchanged still gets a row. Influence uses mean composites for datasets 1–3 and existing composites for dataset 4, without bootstrap. Exceptions and undefined estimate/p pairs remain failed rows.
- The run writes a failure log to `--out/unmet.md` and also copies it alongside the script, satisfying the assignment's `output/unmet.md` destination. Failure to write beside a read-only deployed script does not prevent the required files in `--out`. Package versions, arguments, and captured warnings are recorded in `session_info.txt`.

## Validation

Ran `~/.venv/bin/python output/analysis.py --data input/synthetic --out synthetic_out --seed 20261031 --boot 200`. Confirmed all four required output files, exact manifest coverage of 12,710 result identities, all 28 key families, and 7,362 influence identities covering every specified estimand and retained unit. All result quantities and influence refits in this synthetic execution have status `ok`. Bootstrap fit discards are counted in the specified keys and listed in `unmet.md`. Independent computational checks covered OLS path/delta calculations, Student and Welch tests, logistic HC0, missing-item masking, failed bootstrap fits, and empty samples. No substantive interpretation of synthetic estimates was made.
