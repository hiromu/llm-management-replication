# Pre-execution check

Read ./input/manifest.md and the script in ./input/code/. Do not run anything and do not change anything.

Return in ./output/unmet.md a bare list of manifest items the code does not meet, each one line naming the manifest item and where in the code the problem is. Report only unmet items: no praise, no style comments, no statistical opinions beyond the manifest. If every item is met, write the single line: NONE. Then print only the word DONE.
