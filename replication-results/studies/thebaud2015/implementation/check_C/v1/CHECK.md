1. Manifest sections 1 and 3, growth count coding — `run.jl` lines 203 and 274–278 restrict both job counts to 0–999998. The manifest specifies this range for size, but defines missing growth counts by the listed missing codes or empty cells; other nonmissing counts above 999998 are incorrectly discarded.
2. Manifest section 3, U23 growth — `run.jl` lines 277–278 check only OMYR5JOB for missingness, producing nonmissing growth when OMNOWJOB is missing, although the growth specification requires missingness when either count is missing.
3. Manifest section 6, year references — `run.jl` lines 508–518 replace an absent prescribed reference year with the earliest observed year. This changes the required reference, including for N01 models M3–M7 after 2001 and 2002 are removed.
4. Manifest section 8.2, run order — `run.jl` lines 123–150 and 914–921 order deviations numerically instead of in the listed manifest order; for example, U03 and U04 run before U05 and the remaining deviations in the first manifest group.
5. Manifest section 8, selection of all runs — `run.jl` lines 897–898 expand `all` to ORIGIN and deviations only, omitting the influence runs required by section 8.3.
6. Manifest section 8, failure handling — `run.jl` lines 938–950 call `prepare_run` for ORIGIN and influence without an exception handler. A preparation error, such as computing standardization means from an empty M3 sample at lines 420–442, terminates execution instead of recording the error and continuing to subsequent requested runs.

Manifest section 8, one output row per model term — `run.jl` lines 703–708, 730–736, 795–801, 815 and 834–835 emit a single failed row with an empty term instead of rows for the model's fixed terms.
