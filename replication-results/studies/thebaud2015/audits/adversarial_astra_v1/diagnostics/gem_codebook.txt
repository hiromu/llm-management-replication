                       ICPSR PROCESSING NOTES FOR #20320
    Global Entrepreneurship Monitor [GEM]: Adult Population Survey Dataset 1998-2017
                                 DS #1: Public-Use Data


1. Stata Limitations:
      a. Due to Stata limitations, the variable CTRYALP does not contain value labels for non-
         integer values within the Stata files.

      b. Due to Stata limitations, the variable SETID_NE had to be converted to a string
         because Stata is not able to add labels to numeric values wider than 10 digits.
      c. Due to Stata limitations, the variables BAFUND, SUMONTOT, and SUMONOWN had
         to be converted from comma type numeric to a string because Stata is not able add
         labels to numeric values.

2. Extent of Processing: The size of the dataset resulted in many limitations during processing;
   therefore, this collection has been minimally processed by ICPSR.


3. Additional Information: For additional information on the Global Entrepreneurship Monitor
   [GEM]: Adult Population Survey study, please visit the http://gemconsortium.org/ website.
