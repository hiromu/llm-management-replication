## Contradictions and reporting gaps

- MAIN p.14 refers to Panel B of appendix Table A1 for owner descriptives; the actual location is S1 p.2, Table A2 Panel B. S1 p.1 Table A1 has country-level summaries. This is also identified in the packet metadata.
- MAIN p.13 calls the economic control GDP per capita, whereas S1 p.1 explicitly calls it GDP index. The source dictionary distinguishes the old UNDP GDP index from GDP per capita and the later GNI income index. I retained the conceptual ambiguity instead of silently privileging one.
- S1 p.3 Table A3 Model 2 leaves fertility blank although MAIN p.14 describes fertility as a control. The closest printed term list omits it for that model only, with a competing inclusion branch. Its AIC accounting is suggestive of an extra parameter under a conventional covariance structure, but numerical coincidence cannot identify a missing term.
- MAIN p.10 says respondents are in the labor force, but footnote 2 and S1 p.3 describe the broader check as including not-employed individuals. These statements do not identify how unemployed job seekers were handled. The provided coarse work-status categories cannot implement a precise labor-force concept.
- MAIN p.14 describes full-time employees for business size, but MAIN pp.31–32 explicitly says employee full-time/part-time status is unknown. Headcount is the available source-based fallback.
- MAIN p.11 uses current owner-manager wording for established owners without stating the GEM duration threshold. Nascent status likewise combines a quoted start-up screen with the active/payment-duration definition in footnote 3. The code mapping cannot be determined from terminology alone.
- MAIN p.14 defines high growth using more than five additional employees; MAIN p.24 abbreviates this to hiring more than five employees. I prioritize the explicit operational definition for the closest origin and label a future-total threshold non-equivalent.
- MAIN p.19 Table 1 Model 2 really prints a negative SE for age squared. S1 p.3 really prints AIC 19950 in Model 3 and 95506.07 in Model 1. MAIN p.22 Model 5 has an AIC/likelihood penalty that is difficult to reconcile with its stated mixed-model structure under conventional marginal ML AIC. These values are preserved, not corrected. The evidence is documented in forensic_observations.json with full rounding-interval checks and stated assumptions.
- S1 p.1 really prints part-time-employment SD 0.23 despite its wide percentage-point range; ordinary same-scale SD arithmetic cannot reconcile it. MAIN p.22 Model 6 intercept is unmarked despite a very large coefficient/SE ratio under a normal test. This is only a possible annotation omission; no-star is not a published nonsignificance test.
- Software, estimator command/version, integration settings, convergence criteria, ML versus REML for business size, intercept/slope covariance matrices, survey weights, native SE calculation, test reference distributions, tails, finite-cluster corrections and multiplicity policy are not stated (MAIN p.15 and table notes). A citation to a Stata-oriented methods book on MAIN p.39 is not proof that Stata or any particular command/default was used.
