# Software: Python

Use Python 3.13 at ~/.venv/bin/python (run scripts with the -I flag). Available packages: numpy 2.4.2, scipy 1.16.3, pandas 2.2.3, statsmodels 0.14.6, semopy 2.3.11, numdifftools 0.9.42. Do not install packages. You may write your own maximum-likelihood estimator with numpy/scipy (recommended for exact control of constraints) or use semopy where it supports the specification. R must not be used. Record package versions in every output.
