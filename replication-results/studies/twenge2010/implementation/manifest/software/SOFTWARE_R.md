# Software: R

Use R via `Rscript` (R 4.6.1, /opt/homebrew/bin/Rscript). Installed packages you may use: lavaan 0.7.3, data.table, jsonlite, numDeriv, sandwich, readr, and base/recommended packages. Do not install packages. Documentation is available offline through R itself (for example `Rscript -e 'help(lavaan::lavaan)'` or `?lavOptions` via `tools::Rd2txt`). Record sessionInfo() in every output.
