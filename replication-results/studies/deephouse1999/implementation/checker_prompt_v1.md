# Pre-execution check

This directory contains a specification (`manifest.md`, `grid.json`) and code written to implement it (`code/`). Do not run the code and do not modify any file.

Read the specification and the code. Return only a bare numbered list of specification items that the code does not implement or implements differently from the specification. Each line: the manifest section or grid level id, then one sentence saying what is missing or different, citing the code file and line. Do not suggest fixes, do not rate quality, do not comment on items that are correct. If every item is met, return exactly: NO UNMET ITEMS.

Write the list to `unmet_items.md` and also return it as your final message.
