# Pre-execution check

This directory contains a specification (`implementation_spec.md`, `grid_v1.json`) and code written by someone else (`code/`). You do not have, and must not use, any data.

Read the specification and the code. Do not run the code. Write `check_output.md` containing only a bare numbered list of specification items that the code does not implement or implements differently from the specification. Cite the spec section and the code file/line for each item. If every item is met, write the single line `No unmet items.` Do not suggest improvements, style changes or alternative specifications.
