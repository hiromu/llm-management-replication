# Pre-execution check (v1.1)

This directory contains a specification (`implementation_spec.md`, `grid_v1.json`), an amendment (`spec_amendment_v1_1.md`, which takes precedence where they differ) and code written by someone else (`code/`). You do not have, and must not use, any data.

Read the specification, the amendment and the code. Do not run the code. Write `check_output.md` containing only a bare numbered list of specification or amendment items that the code does not implement or implements differently. Cite the spec/amendment section and the code file/line for each item. If every item is met, write the single line `No unmet items.` Do not suggest improvements, style changes or alternative specifications.
