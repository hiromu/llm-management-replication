Spec section 2 ("Apply declared missing codes per variable from the metadata unless a rule below says otherwise") with section 4.4 (V157 code 99996 is to be used as 100000) and section 4.11 (V261 code 96 is to be used as 100 under hierarchy L0/L2): `clean_data` applies the metadata declared-missing codes first (code/run_grid.R:20-35), and the top-code replacements are then applied to the already-cleaned values (code/run_grid.R:75 for V157, code/run_grid.R:96-97 for V261). If the metadata declares 99996 for V157 or 96 for V261 as missing, those rows become missing instead of taking the spec's substituted values. The only exemption implemented is the STAFF code 995 under staff_coding L2 (code/run_grid.R:26), and that exemption covers `declared_missing_values` only, not `declared_missing_ranges` (code/run_grid.R:28-31), so a declared range containing 995 would still make it missing contrary to section 4.3 L2.
