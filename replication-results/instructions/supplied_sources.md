# User-supplied original source bundles

A study may hold original source files that the user, a human, downloaded and saved by hand. They sit in that study's own data/supplied/ folder, inventoried with hashes and provenance in data/supplied/supplied_sources.json. Such a bundle is a limited exception to reacquiring every dataset and dictionary during the session. It belongs to that study only; no other study may read it. The study's CLAUDE.md and STUDY.json say whether it has one. No agent downloaded these files.

After research is authorized, the source role must compare the actual files with the setup inventory, verify release and provider identity, review access terms and missing components, and create a new study-local registry. Copy-time checksums do not certify data completeness or analytic suitability. A provider manifest listing a file is not evidence that the file is present. Record the provenance as a human download by the user, with the download time unknown unless evidence establishes it. Distinguish the provider's release date, the setup-copy time and any later download. Preserve provider manifests and terms-of-use files.

Keep supplied files immutable and leave data/supplied/ unchanged; derived files go in data/derived/ and newly acquired sources in data/raw/. Do not log in to, register with, accept terms from or download from the provider of a supplied bundle on the user's behalf. If a file from that provider is missing, stop and ask the user to download it. Record it as a new inventory version with its hash, not as present at setup. Retain original filenames and do not prefilter countries or variables. All other empirical source inputs must be acquired afresh from public sources under the shared rules.

An original source collection is not a replication package for the focal article. Recheck the separate no-focal-author-package requirement. Provider import syntax, if supplied later, may document data formats; it must be reviewed and limited to importing the original source. It cannot replace independent implementation of the article's sample, variables or estimators.

Readers never receive numeric source data or unfiltered codebooks with numerical summaries. Prepare fresh source descriptions and summary-free dictionaries for them, and never copy data/supplied/ into a reader's staging directory. The implementation registry bundle must be neutral and target-free. No research or model fitting is performed by preparing or copying source files.
