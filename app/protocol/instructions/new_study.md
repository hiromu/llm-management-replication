# Console workspace entry point

Read ../CLAUDE.md (from this file) and the active study's STUDY.json. The console
has created a fresh workspace for exactly one uploaded paper. Paths are relative
to the workspace root, never to the console installation or a historical archive.

The active study ID and export ID are in console/context.json. Read the full shared
protocol, including eligibility and source checks, before starting. Research is
authorized only if the launch instruction and STUDY.json say so. A readiness run
does not authorize downloads, model roles or statistical fitting.

Use only the uploaded article, its supplements and sources acquired or supplied
for this study. Never inspect another run or a result archive. Report unavailable
models, packages or data honestly; do not substitute models or invent findings.

The workspace's protocol-manifest.json records the exact instructions used. Keep
that record alongside the study's frozen scientific rules and actual model/runtime
metadata. Follow console/output-instructions.md for progress and structured export.
Published targets remain sealed from implementers as required by the protocol;
console output instructions are for the coordinator/exporter, not implementers.
